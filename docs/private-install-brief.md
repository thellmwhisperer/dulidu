# Private install line

Dulidu's README tells a reader to install with:

    curl -fsSL https://raw.githubusercontent.com/thellmwhisperer/dulidu/main/install.sh | sh

That URL returns 404 while the repository is private. A reader who already has the clone should run the install.sh that is in the clone, with DULIDU_PREFIX set to the directory they choose. Keep the curl line, labelled as the form for a public repository.

Docs only. One README paragraph. No installer code, no new command, no Windows, no signing.
